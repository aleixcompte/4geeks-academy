# Generador de Excusas CLI

Proyecto de Python de 4Geeks Academy (FLEX).

El programa genera una excusa aleatoria combinando tres listas: quién, qué ocurrió y cuándo. Utiliza una función y `random.choice()` para crear una frase diferente en cada ejecución.

## Ejecutar

```bash
python3 app.py
```

## Comprobación

El programa se ejecutó correctamente en Codespaces. Se realizaron seis ejecuciones sin errores y las últimas cinco produjeron combinaciones diferentes.
